# Погода в командной строке на TypeScript

`index.ts` описывает интерфейс консольного приложения на Commander и Chalk. Он принимает название города, флаг прогноза и команды для списка избранных городов.

## Структура

Точка входа импортирует `api` для запросов о погоде, `storage` для избранного и `formatter` для вывода. Эти модули и манифест зависимостей отсутствуют в этой папке. Для запуска нужна полная копия проекта.

## Параметры

- `--city <город>` задаёт город.
- `--forecast` переключает вывод на прогноз.
- `--add-favorite <город>` добавляет город в избранное.
- `--favorites` запрашивает погоду для избранных городов.
